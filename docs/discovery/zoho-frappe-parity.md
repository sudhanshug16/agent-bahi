# Zoho Books and Frappe Books Feature Parity Matrix

**Research cutoff:** 21 August 2026
**Status:** Discovery research baseline; reference sources only; not legal advice and not product documentation.

This document compares core bookkeeping features between **Zoho Books (India)** and **Frappe Books** to inform agent-bahi design decisions. The goal is to use Zoho as a behavioral parity target—ensuring agent-bahi covers similar accounting and compliance use cases—while preserving agent-bahi's stricter requirements for tenant isolation, reversal lineage, evidence, and deterministic CLI behavior.

**Frappe Books License & Reference Policy**: Frappe Books is distributed under AGPL-3.0 (verified from https://github.com/frappe/books/blob/main/LICENSE). Per [[T-002: Frappe Books as Behavior/Concept Reference Only]] in tentative-decisions.md, Frappe Books is treated as **concept and behavior reference only**. No code, schema, UI patterns, or prose are copied. Concepts may inform design but are documented in agent-bahi's own words. Agent-bahi's recommended license (Apache-2.0) is **tentative only**; owner review and explicit approval are required before finalizing any license choice.

## How to Read This Matrix

Each section separates three kinds of statements:

1. **VERIFIED BEHAVIOR (ZOHO/FRAPPE)** — Confirmed from official Zoho Books India help or Frappe Books GitHub documentation, with source links. Subject to change; links must be rechecked for the relevant region/version.

2. **AGENT-BAHI DESIGN CHOICE** — The deterministic model and boundary selected for this repository. Not a claim that Zoho/Frappe mandates a particular software design, but rather how agent-bahi will handle the feature based on its stricter architectural constraints.

3. **SCOPE DECISION** — Whether the feature is Core V1, Deferred, or Open Research (requires external verification before implementation).

A blank or "NOT CONFIRMED" cell indicates the feature could not be verified from official sources.

## Summary and Agent-Bahi Differences from Zoho/Frappe

### Key Differences (Agent-Bahi Stricter Than Zoho)

1. **Immutable Reversal Lineage**: Zoho allows direct edits to posted documents. Agent-bahi requires explicit reversal + replacement, preserving full correction lineage (original → reversal → replacement).

2. **Evidence-Linked Compliance**: Agent-bahi links every GST ITC claim, TDS deduction, and statutory output to supporting evidence (bills, bank statements, receipts, portal acknowledgements). Zoho allows posting without explicit evidence attachment.

3. **Deterministic CLI Engine**: Agent-bahi's engine is deterministic and versioned; non-deterministic decision-making (AI matching, auto-rate selection, hidden heuristics) is explicitly pushed to skills/agents. Zoho includes built-in automation and heuristics.

4. **Tenant Isolation**: Agent-bahi enforces strict independent-tenant architecture with no cross-tenant relationships. Zoho organizations are isolated but support consolidation logic.

5. **Period-Locking Unlock Control**: Agent-bahi requires explicit reason, human actor, audit record, and impact preview for unlock. Zoho unlock is typically a permission check.

6. **Export-Only Government Filing** (settled for GSTR-1): Agent-bahi generates export (JSON, CSV) and user manually files on portal. Zoho supports optional GSP/portal API submission (if configured). Other filings (TDS, payroll, e-invoice) are prepare/validate/export-only in agent-bahi pending research.

### Key Similarities (Agent-Bahi Aligned with Zoho Behavior)

1. **Multi-GSTIN Support**: Agent-bahi supports multiple GST registrations per tenant, matching Zoho's model.

2. **GST Compliance Workflow**: GSTR-1 invoicing, GSTR-3B reconciliation, ITC tracking, and reverse-charge posting align with Zoho.

3. **Multi-Currency and FX**: Immutable rate snapshots and separate realized/unrealized gain-loss align with Zoho's model.

4. **Payroll Computation**: Full India payroll (salary structure, statutory deductions, form generation) aligns with Zoho's scope.

5. **Bank Reconciliation**: Transaction matching and cleared/outstanding tracking align with Zoho's workflow.

6. **Reporting Dimensions (Tags)**: Filtering and grouping via tags/cost centers for non-tax reporting aligns with Zoho.
